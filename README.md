# Hi, I'm @aseawa

I'm working on Paper Studio, an open-source workspace for studying PDFs.

### Paper Studio

Use a digital pen or mouse to write on exam papers, worksheets and other PDFs. Track time by page, record multiple-choice answers and export an annotated PDF with study data.

[Open the app](https://aseawa.github.io/paper-studio/) · [View the project](https://github.com/aseawa/paper-studio) · [English guide](https://github.com/aseawa/paper-studio/blob/main/README.md)
